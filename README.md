# android_system_core

Fork of `LineageOS/android_system_core` for the **LG G Pad X 8.0 (V521)**
LineageOS 15.1 port.  The port builds from `lineage-15.1-v521`; the other
branches are upstream.

Changes:

* None in the code any more.  The `flash_recovery` trigger was disabled
  while the device had TWRP and has been restored; the ROM now keeps the
  recovery partition up to date.

Port and device tree: <https://github.com/MicahOttah/android_device_lge_v521>
